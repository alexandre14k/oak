# oak
oak displays files and folders in a tree structure

![Visitors](https://api.visitorbadge.io/api/VisitorHit?user=alexandre14k&repo=https://github.com/alexandre14k/oak&label=Views&labelColor=%23555555&countColor=%23007EC6)

## features
- display files and folders in a tree structure
- exclude specific paths
- filter files by extension
- limit directory depth
- show help and usage options
